# Three Fronts

2D로 운영하고, 3D에서 실시간으로 싸우는 비대칭 3종족 RTS 프로토타입입니다.
장르 공통 구조(자원 2종, 인구수, 실드/방어력, 공격 타입×크기 배율)를 쓰고, 종족·유닛·수치·아트는 모두 오리지널입니다.

## 실행

```bash
cd rts-3d
npm install
npm run dev     # http://localhost:5173
npm test        # 시뮬레이션 단위 테스트
npm run build
```

## 플레이

1. 종족을 선택합니다.
2. **2D 운영 모드**: 왼쪽 패널에서 건설, 일꾼 배치, 생산을 하고, 오른쪽 2D 전장 지도로 전황을 봅니다.
3. **교전이 발생하면 3D 전투 모드로 자동 전환**되고, 아군 유닛이 전체 선택된 채로 시작합니다.
   - 교전이 끝나고 6초 동안 조작이 없으면 2D로 자동 복귀합니다. 직접 3D로 들어왔다면 자동 복귀하지 않습니다.
   - `Tab`을 누르거나 지도를 클릭하면 언제든 전환할 수 있습니다. 자동 전환은 체크박스로 끌 수 있습니다.
4. 적 AI는 2:30부터 90초마다 공격 웨이브를 보냅니다. 적 본진을 파괴하면 승리합니다.

### 3D 전투 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 / 드래그 | 유닛 선택 (Shift: 추가 선택) |
| 우클릭 (땅) | 이동: 적을 무시하고 이동한 뒤 그 자리 방어 |
| 우클릭 (적) | 해당 적 집중 공격 |
| Shift+우클릭, `A` → 좌클릭 | 공격 이동 |
| `S` | 정지 (그 자리 방어) |
| `Ctrl+A` | 전체 선택 |
| 휠 / 가운데 드래그 / 방향키 | 줌 / 회전 / 화면 이동 |

하단 도크에서 공격 진격, 후퇴, 빠른 생산을 할 수 있습니다. 빠른 생산은 큐가 가장 짧은 생산 건물에 자동으로 넣습니다.

## 종족

| 종족 | 정체성 | 고유 규칙 |
|---|---|---|
| Coalition | 인간 기계문명, 방어와 화력 | 건물 자동 수리 (전투 외 10초 후) |
| Swarm | 생체 군집, 물량 | 전 유닛 체력 재생 |
| Ascendant | 에너지 고대종, 소수 정예 | 실드 재생 (피격 7초 후) |

| 원형 | Coalition | Swarm | Ascendant |
|---|---|---|---|
| 일꾼 | Rigger | Mite | Shaper |
| 기본 보병 | Trooper | Skitter | Warden |
| 원거리 | Lancer | Spitter | Arc Sentinel |

수치는 `src/data/factions.js`, 피해 규칙은 `src/data/rules.js`에서 조정합니다.

| 공격 타입 | small | medium | large |
|---|---|---|---|
| kinetic | 100% | 100% | 100% |
| explosive | 50% | 75% | 100% |
| plasma | 100% | 50% | 25% |

실드는 타입 배율과 방어력을 무시하고 먼저 소모됩니다.

## 구조

```
rts-3d/
├── index.html
├── src/
│   ├── main.js            # 게임 루프, 2D↔3D 연결
│   ├── style.css
│   ├── data/
│   │   ├── factions.js    # 종족·건물·유닛 스펙
│   │   └── rules.js       # 피해 계산
│   ├── sim/               # 렌더링과 분리된 순수 로직 (테스트 대상)
│   │   ├── economy.js     # 자원·건설·생산 큐·인구수
│   │   ├── combat.js      # 타겟팅·이동·공격·종족 특성
│   │   └── ai.js          # 적 운영 + 웨이브
│   └── view/
│       ├── icons.js       # 2D 아이콘 (2D 맵과 3D 빌보드가 공유)
│       ├── base2d.js      # 2D 운영 화면 (기지)
│       ├── field2d.js     # 2D 전장 지도 (클릭 → 3D 전환)
│       └── battle3d.js    # Three.js 3D 전투 화면 + 선택·명령
└── test/sim.test.js
```
