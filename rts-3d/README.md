# Three Fronts

2D로 운영하고, 교전이 벌어지면 3D 1인칭으로 아군 유닛에 빙의해 직접 싸우는 비대칭 3종족 RTS 프로토타입입니다.

- **싱글 플레이**: AI 상대. 브라우저 안에서 모두 실행 (전투는 Rust WASM)
- **멀티 플레이**: 1대1 온라인. Rust 서버가 게임 전체를 계산하는 권한(authoritative) 서버 방식
- 클라이언트: TypeScript + Three.js + Vite · 서버/전투 코어: Rust

## 실행

```bash
cd rts-3d
npm install

# 싱글 플레이만
npm run dev                      # http://localhost:5173

# 멀티 플레이 (서버 + 클라이언트)
cargo run -p server --release    # 터미널 1: 게임 서버 :8080
npm run dev                      # 터미널 2: /ws 를 :8080으로 프록시
```

배포용으로는 빌드 결과를 서버 하나로 함께 서빙합니다.

```bash
npm run build                    # dist/ 생성
cargo run -p server --release    # http://localhost:8080 에서 게임 + WebSocket
```

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | 서버 포트 |
| `STATIC_DIR` | dist | 함께 서빙할 클라이언트 빌드 경로 |
| `GAME_SPEED` | 1 | 개발·테스트용 배속 |

### 테스트

```bash
npm test             # TS 테스트 (실제 WASM 바이너리 사용, Node 22.18+)
npm run test:rust    # Rust: 전투 코어 + 서버 (WebSocket 통합 테스트 포함)
npm run typecheck
```

전투 코드(`combat-core/`)를 수정하면 WASM을 다시 빌드합니다. 빌드된 `.wasm`은 저장소에 포함돼 있어서 Rust 없이도 싱글 플레이는 바로 실행됩니다.

```bash
rustup target add wasm32-unknown-unknown   # 최초 1회
npm run build:wasm
```

## 멀티 플레이

1. 메뉴에서 **멀티 플레이**를 고르고 종족을 선택합니다.
2. 한 명이 **방 만들기**를 누르면 4자리 방 코드가 나옵니다.
3. 다른 한 명이 코드를 입력하고 **참가**하면 바로 시작합니다.

- 서버가 경제·생산·전투를 모두 계산합니다. 클라이언트는 명령만 보내므로 자원이나 유닛 수를 조작할 수 없습니다.
- 상대의 경제(자원·건물)는 보이지 않고, 전장의 유닛과 본진만 공개됩니다.
- 게임 속도는 1배로 고정됩니다. 1인칭 빙의는 양쪽 모두 가능합니다.
- 상대가 나가면 남은 쪽이 승리합니다.

### 네트워크 구조

```
브라우저 A ─┐  명령(JSON)             ┌─ 경제 × 2 (server/src/economy.rs)
            ├──────────▶ Rust 서버 ───┤  전투 (combat-core, 네이티브)
브라우저 B ─┘ ◀──────────  30Hz 시뮬  └─ 방 코드 로비 (axum WebSocket)
             15Hz 스냅샷 (자기 시점)
```

- **위치 보간**: 스냅샷 사이 유닛 위치를 부드럽게 이어 그립니다.
- **1인칭 예측**: 빙의한 유닛은 입력 즉시 로컬에서 움직이고, 서버 위치로 서서히 보정합니다.
- **입력 검증**: 서버가 이동 입력 크기를 1로 제한하고, 자기 유닛만 명령·빙의할 수 있습니다.
- **빙의 실패 처리**: 지연 중 유닛이 죽어 서버가 빙의를 거부하면, 가까운 다른 아군으로 자동 전환합니다.

## 규칙

- **유닛 상한**: 플레이어당 전투 유닛 **100기**. 일꾼은 제외하고, 생산 대기 중인 유닛은 포함합니다. 유닛이 죽으면 다시 생산할 수 있습니다.
- **인구수**: 최대 100. 공급 건물로 늘립니다.
- 적 AI(싱글)는 2:30부터 90초마다 공격 웨이브를 보냅니다. 적 본진을 파괴하면 승리합니다.

## 조작

교전이 발생하면 3D 1인칭으로 자동 전환되고, 교전 지점에서 가장 가까운 아군 유닛에 빙의합니다. 화면을 클릭하면 마우스 조준이 시작됩니다.

### 1인칭 빙의

| 입력 | 동작 |
|---|---|
| 마우스 | 조준 (조준점: 흰색 = 대상 없음, 빨강 = 사거리 안, 주황 = 사거리 밖) |
| 좌클릭 (누르고 있기) | 사격. 유닛의 실제 피해·쿨다운·사거리를 그대로 사용 |
| `W` `A` `S` `D` | 이동 |
| `1`~`9` | 다른 아군 유닛으로 전환 |
| `V` | 전술 시점으로 |
| `Tab` | 2D 운영 화면으로 |
| `Esc` | 마우스 잠금 해제 |

### 전술 시점

| 입력 | 동작 |
|---|---|
| 좌클릭 / 드래그 | 유닛 선택 (Shift: 추가 선택) |
| 우클릭 (땅 / 적) | 이동 / 집중 공격 |
| Shift+우클릭, `A` → 좌클릭 | 공격 이동 |
| `S` / `Ctrl+A` | 정지 / 전체 선택 |
| `V` | 선택한 유닛에 빙의 |
| 휠 / 가운데 드래그 / 방향키 | 줌 / 회전 / 화면 이동 |

## 종족

| 종족 | 정체성 | 고유 규칙 |
|---|---|---|
| Coalition | 인간 기계문명, 방어와 화력 | 건물 자동 수리 (전투 외 10초 후) |
| Swarm | 생체 군집, 물량 | 전 유닛 체력 재생 |
| Ascendant | 에너지 고대종, 소수 정예 | 실드 재생 (피격 7초 후) |

| 원형 | Coalition | Swarm | Ascendant |
|---|---|---|---|
| 일꾼 | Rigger | Mite | Shaper |
| 기본 보병 | Trooper | Skitter | Warden |
| 원거리 | Lancer | Spitter | Arc Sentinel |

| 공격 타입 | small | medium | large |
|---|---|---|---|
| kinetic | 100% | 100% | 100% |
| explosive | 50% | 75% | 100% |
| plasma | 100% | 50% | 25% |

실드는 타입 배율과 방어력을 무시하고 먼저 소모됩니다.
수치는 `shared/factions.json` 하나만 고치면 클라이언트와 서버에 함께 반영됩니다. 피해 규칙은 `combat-core/src/world.rs`에 있습니다.

## 구조

```
rts-3d/
├── Cargo.toml             # Rust 워크스페이스
├── shared/factions.json   # 종족 데이터 (TS·Rust 공용)
├── combat-core/           # Rust 전투 코어 → WASM(싱글) + 네이티브(서버)
│   └── src/
│       ├── world.rs       # 타겟팅·이동·피해·종족 특성·빙의
│       └── lib.rs         # WASM 숫자 ABI
├── server/                # Rust 멀티플레이 서버 (axum + tokio)
│   ├── src/
│   │   ├── lib.rs         # WebSocket 로비·방 코드·게임 루프
│   │   ├── game.rs        # 권한 게임 상태 (경제 × 2 + 전투)
│   │   ├── economy.rs     # 경제 (TS economy.ts 이식)
│   │   ├── factions.rs    # shared/factions.json 로딩
│   │   └── protocol.rs    # 메시지 타입
│   └── tests/ws.rs        # 두 클라이언트 WebSocket 통합 테스트
├── src/
│   ├── main.ts            # 메뉴: 싱글 / 멀티(방 만들기·참가)
│   ├── game.ts            # 게임 화면·프레임 루프 (세션 공통)
│   ├── session/
│   │   ├── session.ts     # Session 인터페이스
│   │   ├── local.ts       # 싱글: 경제·AI(TS) + 전투(WASM)
│   │   └── remote.ts      # 멀티: 서버 스냅샷 보간 + 1인칭 예측
│   ├── net/protocol.ts    # 메시지 타입 (server/src/protocol.rs와 일치)
│   ├── sim/
│   │   ├── economy.ts     # 자원·건설·생산·인구수·유닛 상한
│   │   ├── combat.ts      # Rust WASM 래퍼
│   │   ├── ai.ts          # 적 AI (싱글)
│   │   └── wasm/combat_core.wasm
│   └── view/              # 2D 운영 · 2D 전장 지도 · 3D(1인칭/전술)
└── test/sim.test.ts
```

## 성능 (전투 코어, Node 22, 1/30초 스텝 평균)

| 유닛 수 | TypeScript | Rust WASM | 배율 |
|---|---|---|---|
| 100 | 0.17 ms | 0.08 ms | 2.1× |
| 500 | 1.61 ms | 0.78 ms | 2.1× |
| 2,000 | 26.78 ms | 11.04 ms | 2.4× |

두 구현에 같은 최적화를 적용한 공정 비교입니다. 유닛 상한(플레이어당 100기, 최대 200기)이면 한 스텝이 0.2ms 안팎입니다.
