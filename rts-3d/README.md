# Three Fronts

2D로 운영하고, 3D에서 실시간으로 싸우는 비대칭 3종족 RTS 프로토타입입니다.
장르 공통 구조(자원 2종, 인구수, 실드/방어력, 공격 타입×크기 배율)를 쓰고, 종족·유닛·수치·아트는 모두 오리지널입니다.

## 실행

```bash
cd rts-3d
npm install
npm run dev     # http://localhost:5173
npm test        # 시뮬레이션 단위 테스트
npm run build
```

## 플레이

1. 종족을 선택합니다.
2. **왼쪽 2D 운영 화면**에서 건물을 짓고, 일꾼을 배치하고, 맵에서 생산 건물을 선택해 유닛을 생산합니다.
3. **오른쪽 3D 전투 화면**에서는 생산된 유닛이 실시간으로 싸웁니다. 드래그로 회전하고, 휠로 확대·축소합니다.
4. `공격 진격` / `기지 방어` 버튼으로 군대에 명령합니다. 적 본진을 파괴하면 승리, 내 본진이 파괴되면 패배입니다.
5. 적 AI는 2:30부터 90초마다 공격 웨이브를 보냅니다. 오른쪽 위 버튼으로 게임 속도를 1×, 2×, 4×로 바꿀 수 있습니다.

## 종족

| 종족 | 정체성 | 고유 규칙 |
|---|---|---|
| Coalition | 인간 기계문명, 방어와 화력 | 건물 자동 수리 (전투 외 10초 후) |
| Swarm | 생체 군집, 물량 | 전 유닛 체력 재생 |
| Ascendant | 에너지 고대종, 소수 정예 | 실드 재생 (피격 7초 후) |

| 원형 | Coalition | Swarm | Ascendant |
|---|---|---|---|
| 일꾼 | Rigger | Mite | Shaper |
| 기본 보병 | Trooper | Skitter | Warden |
| 원거리 | Lancer | Spitter | Arc Sentinel |

수치는 `src/data/factions.js`, 피해 규칙은 `src/data/rules.js`에서 조정합니다.

| 공격 타입 | small | medium | large |
|---|---|---|---|
| kinetic | 100% | 100% | 100% |
| explosive | 50% | 75% | 100% |
| plasma | 100% | 50% | 25% |

실드는 타입 배율과 방어력을 무시하고 먼저 소모됩니다.

## 구조

```
rts-3d/
├── index.html
├── src/
│   ├── main.js            # 게임 루프, 2D↔3D 연결
│   ├── style.css
│   ├── data/
│   │   ├── factions.js    # 종족·건물·유닛 스펙
│   │   └── rules.js       # 피해 계산
│   ├── sim/               # 렌더링과 분리된 순수 로직 (테스트 대상)
│   │   ├── economy.js     # 자원·건설·생산 큐·인구수
│   │   ├── combat.js      # 타겟팅·이동·공격·종족 특성
│   │   └── ai.js          # 적 운영 + 웨이브
│   └── view/
│       ├── icons.js       # 2D 아이콘 (2D 맵과 3D 빌보드가 공유)
│       ├── base2d.js      # 2D 운영 화면
│       └── battle3d.js    # Three.js 3D 전투 화면
└── test/sim.test.js
```
