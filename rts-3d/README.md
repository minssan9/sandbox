# Three Fronts

2D로 운영하고, 교전이 벌어지면 3D 1인칭으로 아군 유닛에 빙의해 직접 싸우는 비대칭 3종족 RTS 프로토타입입니다.
TypeScript + Three.js + Vite로 만들었습니다.
장르 공통 구조(자원 2종, 인구수, 실드/방어력, 공격 타입×크기 배율)를 쓰고, 종족·유닛·수치·아트는 모두 오리지널입니다.

## 실행

```bash
cd rts-3d
npm install
npm run dev     # http://localhost:5173
npm test        # 시뮬레이션 단위 테스트 (Node 22.18+의 TypeScript 직접 실행 사용)
npm run typecheck
npm run build   # tsc 타입 검사 + 번들
```

## 플레이

1. 종족을 선택합니다.
2. **2D 운영 모드**: 왼쪽 패널에서 건설, 일꾼 배치, 생산을 하고, 오른쪽 2D 전장 지도로 전황을 봅니다.
3. **교전이 발생하면 3D 1인칭으로 자동 전환**되고, 교전 지점에서 가장 가까운 아군 유닛에 빙의합니다.
   - 화면을 클릭하면 마우스 조준이 시작됩니다(포인터 잠금).
   - `V`로 전술 시점(위에서 내려다보기)과 1인칭을 오갈 수 있습니다.
   - `Tab`을 누르거나 2D 지도를 클릭하면 언제든 전환할 수 있습니다. 지도를 클릭하면 그 지점에서 가장 가까운 유닛에 빙의합니다.
   - 전술 시점으로 자동 진입한 경우에는 교전이 끝나면 2D로 돌아갑니다. 1인칭 중에는 안내만 표시합니다.
4. 적 AI는 2:30부터 90초마다 공격 웨이브를 보냅니다. 적 본진을 파괴하면 승리합니다.

### 1인칭 빙의 조작

| 입력 | 동작 |
|---|---|
| 마우스 | 조준 (조준점: 흰색 = 대상 없음, 빨강 = 사거리 안, 주황 = 사거리 밖) |
| 좌클릭 (누르고 있기) | 사격. 유닛의 실제 피해·쿨다운·사거리를 그대로 사용 |
| `W` `A` `S` `D` | 이동 (유닛 이동 속도 적용) |
| `1`~`9` | 다른 아군 유닛으로 빙의 전환 |
| `V` | 전술 시점으로 |
| `Esc` | 마우스 잠금 해제 |

빙의 중인 유닛이 죽으면 가장 가까운 아군으로 자동 전환되고, 아군이 없으면 전술 시점으로 돌아갑니다. 빙의를 해제한 유닛은 그 자리를 방어합니다.

### 전술 시점 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 / 드래그 | 유닛 선택 (Shift: 추가 선택) |
| 우클릭 (땅 / 적) | 이동 / 집중 공격 |
| Shift+우클릭, `A` → 좌클릭 | 공격 이동 |
| `S` / `Ctrl+A` | 정지 / 전체 선택 |
| `V` | 선택한 유닛에 빙의 |
| 휠 / 가운데 드래그 / 방향키 | 줌 / 회전 / 화면 이동 |

## 종족

| 종족 | 정체성 | 고유 규칙 |
|---|---|---|
| Coalition | 인간 기계문명, 방어와 화력 | 건물 자동 수리 (전투 외 10초 후) |
| Swarm | 생체 군집, 물량 | 전 유닛 체력 재생 |
| Ascendant | 에너지 고대종, 소수 정예 | 실드 재생 (피격 7초 후) |

| 원형 | Coalition | Swarm | Ascendant |
|---|---|---|---|
| 일꾼 | Rigger | Mite | Shaper |
| 기본 보병 | Trooper | Skitter | Warden |
| 원거리 | Lancer | Spitter | Arc Sentinel |

수치는 `src/data/factions.js`, 피해 규칙은 `src/data/rules.js`에서 조정합니다.

| 공격 타입 | small | medium | large |
|---|---|---|---|
| kinetic | 100% | 100% | 100% |
| explosive | 50% | 75% | 100% |
| plasma | 100% | 50% | 25% |

실드는 타입 배율과 방어력을 무시하고 먼저 소모됩니다.

## 구조

```
rts-3d/
├── index.html
├── tsconfig.json
├── src/
│   ├── main.ts            # 게임 루프, 2D↔3D 전환, 1인칭 입력 적용
│   ├── types.ts           # 공통 타입
│   ├── style.css
│   ├── data/
│   │   ├── factions.ts    # 종족·건물·유닛 스펙
│   │   └── rules.ts       # 피해 계산
│   ├── sim/               # 렌더링과 분리된 순수 로직 (테스트 대상, 추후 Rust/WASM 이전 후보)
│   │   ├── economy.ts     # 자원·건설·생산 큐·인구수
│   │   ├── combat.ts      # 타겟팅·이동·공격·종족 특성·빙의 이동/사격
│   │   └── ai.ts          # 적 운영 + 웨이브
│   └── view/
│       ├── icons.ts       # 2D 아이콘 (2D 맵과 3D 빌보드가 공유)
│       ├── base2d.ts      # 2D 운영 화면 (기지)
│       ├── field2d.ts     # 2D 전장 지도 (클릭 → 1인칭 진입)
│       └── battle3d.ts    # Three.js 3D: 1인칭 빙의 + 전술 시점
└── test/sim.test.ts
```
